## Prompt

Polish the existing ProTube frontend without changing application behavior or routes.

interactive controls, focus states, spacing, form fields, hover states and the catalog
pagination button. Preserve the responsive layout and accessibility labels, and ensure
the result works on desktop, tablet and mobile widths.
